## About

This repository provides practical Python examples, tutorials, and projects across a wide range of topics. It is designed for:

- **Beginners** learning Python syntax and core concepts
- **Intermediate developers** exploring data analysis, web development, and automation
- **Students** working through structured bootcamp curricula

All Flask apps use:

```
resources/     ← JSON data files (where applicable)
```

**Flask concepts covered across all four apps:**
- `render_template()` — Jinja2 template rendering
- `request.args` — reading GET parameters from the URL
- `request.form` — reading POST form submissions
- `redirect()` — redirecting after form submission
- Base layout inheritance with `{% extends %}` and `{% block %}`
- JSON file loading inside routes with `json.load()`
- SQLite integration (`sqlite3.connect()`, cursor, JOIN query, `fetchall()`)
- Server-side validation (allowed sports list, admin credentials check)

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Rohan-Repo/Python-Codebase.git
cd Python-Codebase
```

### 2. Set up a virtual environment (recommended)

```bash
# Create the virtual environment
python -m venv .venv

# Activate it
.venv\Scripts\activate        # Windows Command Prompt
.venv\Scripts\Activate.ps1   # Windows PowerShell
source .venv/bin/activate     # Mac / Linux
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

> Sub-folders with their own `requirements.txt` (e.g. EDA, Pandas, SQLAlchemy) should be installed individually from inside that folder.

### 4. Launch Jupyter for notebooks

```bash
jupyter notebook
```

### 5. Run Python scripts

```bash
# Base Python examples
python Base-Python-Codebases/TC-SC-Python-Codes/BinarySearch.py

# Utilities
python Intermediate-Python-Codes/Python-Utilities/Misc-Utils/Generate-QR-Code.py

# Tkinter GUI — Welcome app
python Intermediate-Python-Codes/Python-GUI-Related/Tkinter-Codes/Display-Welcome-Msg-1.py

# Tkinter GUI — CSV viewer
python Intermediate-Python-Codes/Python-GUI-Related/Tkinter-Codes/Python-Display-CSV-Data-2.py

# SQLAlchemy CLI (all 4 databases)
cd Intermediate-Python-Codes/DB-Related-Apps/Py-SQLAlchemy-Demo/Py-SQLAlchemy-Multiple-DBs-CLI/DB-Wise-Codes/MySQL-SQLServer-SQLite-PostgreSQL
python query_normal.py

# SQLAlchemy GUI — MVC version
cd Intermediate-Python-Codes/DB-Related-Apps/Py-SQLAlchemy-Demo/Py-SQLAlchemy-Multiple-DBs-TKinter-GUI/GUI-MVC-Code
python view.py

# SQLite direct CRUD
cd Intermediate-Python-Codes/DB-Related-Apps/SQLite/SQLite-Python-Code
python Py-SQLite-Conn.py
```

### 6. Run Flask apps

```bash
cd Intermediate-Python-Codes/Web-Dev-Related/Flask-Framework/Company-Dashboard-App
python app.py
# Open http://127.0.0.1:5000 in your browser
```

### 7. Run Django apps

```bash
cd Intermediate-Python-Codes/Web-Dev-Related/Django-DjangoRestAPI-Codebase/Django-SQLite/Django-Movies-App
python manage.py runserver
# Open http://127.0.0.1:8000 in your browser
```
