# NumPy Codebase for Data Processing

A hands-on NumPy notebook for learning the basics of numerical computing and data processing with Python.

This notebook is based on a video follow-along and covers core NumPy concepts with practical examples.

## Features

- Learn NumPy arrays and how they differ from Python lists
- Create arrays using `array`, `arange`, `linspace`, `zeros`, `ones`, `full`, `eye`, and random functions
- Work with 1D, 2D, and 3D arrays
- Perform indexing, slicing, and boolean filtering
- Use vectorized operations for fast calculations
- Reshape, flatten, transpose, concatenate, and stack arrays
- Perform statistical operations such as sum, mean, median, standard deviation, variance, min, max, `argmin`, and `argmax`
- Explore linear algebra operations like dot product, determinant, inverse, and eigenvalues
- Sort arrays, find unique values, and search data efficiently
